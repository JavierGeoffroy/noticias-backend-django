# Plataforma de Noticias

Sistema backend en Django para la gestión de publicaciones periodísticas: artículos, categorías, autores y lectores en un solo lugar.

## Instalación y ejecución

1. Clonar el repositorio:
   `git clone https://github.com/JavierGeoffroy/noticias-backend-django.git`
2. Entrar a la carpeta del proyecto:
   `cd noticias-backend-django`
3. Crear el ambiente virtual:
   `py -m venv .venv`
4. Activar el ambiente virtual (PowerShell):
   `.venv\Scripts\Activate.ps1`
5. Instalar las dependencias:
   `pip install -r requirements.txt`
6. Ejecutar el servidor:
   `python manage.py runserver`
7. Abrir `http://127.0.0.1:8000/` en el navegador.
